# Ling-Shu---KnowVein（灵枢·知脉）

> 《灵枢》言经络者，所以行气血、营阴阳、决死生。AI 时代的个人知识，也正缺这样一条“脉络”。

灵枢·知脉是面向高校学生、研发人员、知识工作者与终身学习者的 AI 个人知识沉淀与主动学习系统。

项目参加华为 ICT 创新赛赛题一：**基于华为云产品打造 AI 创新应用**。

## 项目简介

用户每天都在使用大模型学习、编程和创作，但有价值的对话容易散落，用完即忘，难以形成可复用的知识体系。灵枢·知脉将用户主动导入的 AI 对话转化为带来源依据的知识节点和关系，并通过图谱、个人知识检索、苏格拉底式追问和间隔复习，推动用户从“让 AI 替我想”走向“与 AI 共同学”。

核心闭环：

```text
对话采集 → 知识抽取 → 人机校验 → 图谱关联
        → 个人知识检索（RAG）→ 苏格拉底式追问 → 间隔复习
```

## 核心能力

- **对话沉淀**：保存用户授权导入的对话，按语义切分并保留来源片段。
- **知识抽取**：使用大模型提取概念、定义、标签、关系和证据引用。
- **人机共建图谱**：候选节点需要用户确认，支持编辑、合并和拒绝，降低错误扩散。
- **个人知识 RAG**：从用户自己的对话和节点中检索内容，回答附带可回溯引用；无依据时明确说明。
- **反认知外包**：根据知识节点生成苏格拉底式追问，先引导回忆，再按需提供提示。
- **间隔复习**：记录“忘了/模糊/记得”等反馈，使用可解释的复习调度生成到期任务。

## 技术架构

```text
React + TypeScript
        │ HTTPS / REST
Python FastAPI 模块化单体
        ├── 对话与知识抽取任务
        ├── 图谱、RAG 与引用校验
        ├── 苏格拉底式学习与复习调度
        └── 华为云 AI Provider 适配层
        │
        ├── RDS：用户、对话、节点、关系、复习数据
        ├── Redis：任务状态、幂等、限流、热点缓存
        ├── OBS：用户主动上传的原始文件与导出文件
        └── CodeArts → ECS / CCE：构建、部署、健康检查与回滚
```

推荐技术栈：React、TypeScript、Cytoscape.js、FastAPI、Pydantic、SQLAlchemy、Alembic、RDS PostgreSQL、Redis、Docker Compose、Nginx。模型端点通过服务端 Provider 适配，具体使用的盘古或 ModelArts 服务以账号区域实际开通情况为准。

## 开发约定

1. 先完成“采集对话 → 抽取 → 确认入图 → RAG 引用 → 复习”的纵向闭环，再扩展插件、协作和复杂云资源。
2. 模型输出必须经过结构化校验，节点和关系必须保留来源证据。
3. 所有业务查询按 `user_id` 做服务端隔离；删除、失败重试和无依据拒答属于核心功能。
4. AK/SK、数据库密码、模型密钥和真实用户对话禁止提交到仓库或写入日志。
5. 未经实测的准确率、学习效果和云服务使用情况不得写成已达成指标。
